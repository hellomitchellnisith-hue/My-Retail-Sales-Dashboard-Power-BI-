# 📊 Retail Sales Analytics Dashboard – Power BI

## 📌 Project Overview

The **Retail Sales Analytics Dashboard** is an interactive Power BI project designed to analyze and monitor retail business performance. The dashboard provides meaningful insights into sales, revenue, profit, customers, products, categories, and regional performance.

It helps businesses understand key trends, identify high-performing areas, and make data-driven decisions through interactive visualizations and KPIs.

---

## 🎯 Project Objectives

- Analyze overall retail sales performance
- Track revenue and profit trends
- Monitor customer performance
- Identify top-performing products and categories
- Analyze regional sales performance
- Compare sales and profitability
- Identify business trends and patterns
- Support data-driven business decisions

---

## 📂 Dataset

The project uses retail sales data containing information related to:

- Orders
- Customers
- Products
- Sales
- Revenue
- Profit
- Categories
- Regions
- Countries
- States
- Cities
- Order Dates

The dataset was cleaned and transformed using **Power Query** before developing the dashboard.

---

## 🔄 Data Preparation

The following data preparation steps were performed:

1. Imported the retail dataset into Power BI
2. Removed unnecessary columns
3. Handled missing and duplicate values
4. Corrected data types
5. Cleaned and standardized categorical fields
6. Created calculated columns where required
7. Built relationships between tables
8. Created DAX measures for KPIs and analysis
